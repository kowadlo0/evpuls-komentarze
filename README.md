# EVpuls — Komentarze czytelników

To publiczne repozytorium służy wyłącznie do przechowywania dyskusji i komentarzy pod artykułami portalu **[EVpuls.pl](https://www.evpuls.pl)** (system [Giscus](https://giscus.app/pl) oparty o GitHub Discussions).

## Zasady dyskusji
- Merytoryczne spory i krytyka marek/modeli EV są jak najbardziej mile widziane.
- Spam, linki reklamowe, groźby, mowa nienawiści oraz publikacja cudzych danych osobowych są automatycznie ukrywane przez system moderacji.
- Pełny regulamin i zasady zgłaszania naruszeń (DSA): **[evpuls.pl/regulamin-i-prywatnosc](https://www.evpuls.pl/regulamin-i-prywatnosc/)**.
